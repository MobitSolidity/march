# بازاریار (اندروید)

اپ Kotlin + Jetpack Compose، راست‌به‌چپ، با سه تب:

- **اخبار**: تقویم انتشارهای مهم اقتصادی به وقت تهران، شمارش معکوس زنده، فیلتر «فقط پراهمیت» و یادآور (اعلان ۱۰ دقیقه قبل).
- **بازار**: ۱۰۰ ارز برتر با قیمت زنده از CoinGecko (هر ۶۰ ثانیه)، جستجو، نمودار ۲۴ ساعته و ستاره برای واچ‌لیست.
- **واچ‌لیست**: ارزهای ستاره‌دار و یادآورهای خبری، ذخیره‌شده روی گوشی (DataStore).

حداقل اندروید ۸ (API 26).

## ساخت APK

**راه ۱: Android Studio**
1. پوشه را با Android Studio (نسخه Koala یا جدیدتر) باز کن و صبر کن Gradle sync شود.
2. Build › Build App Bundle(s) / APK(s) › Build APK(s).
3. فایل در `app/build/outputs/apk/` ساخته می‌شود.

**راه ۲: بدون نصب چیزی (GitHub Actions)**
1. پوشه را در یک ریپوی GitHub پوش کن.
2. تب Actions › Build APK اجرا می‌شود؛ بعد از چند دقیقه APK را از بخش Artifacts دانلود کن.

APK ریلیز با کلید debug امضا شده تا مستقیم نصب شود. قبل از انتشار در کافه‌بازار/گوگل‌پلی کلید اختصاصی بساز.

## نکته‌ها

- **دسترسی از ایران:** CoinGecko ممکن است برای IPهای ایران محدود باشد. اگر تب بازار خطای اتصال داد، با VPN تست کن یا آدرس API را در `data/CoinRepository.kt` به یک سرویس داخلی (مثل API نوبیتکس/والکس) عوض کن.
- **تقویم خبرها** در `data/Events.kt` است (از تقویم فدرال رزرو و BLS، اکتبر ۲۰۲۶). ماهانه به‌روزش کن یا به یک API تقویم اقتصادی وصلش کن.
- یادآورها بعد از ری‌استارت گوشی پاک می‌شوند؛ با باز کردن دوباره‌ی اپ و زدن زنگوله دوباره تنظیم کن.
- فونت پیش‌فرض سیستم استفاده شده؛ برای وزیرمتن فایل‌های فونت را در `res/font` بگذار و در `Theme.kt` به Typography بده.
